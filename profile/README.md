# CodeLABS • JMIT Radaur

> Official Student Technical & Computing Club at Seth Jai Parkash Mukand Lal Institute of Engineering and Technology (JMIT), Radaur, Haryana, India.

## Organization Summary

CodeLABS is a student-led engineering, research, and software development club dedicated to elevating technical rigor among undergraduate engineering students. Founded in August 2026, the club focuses on hands-on project architectures, algorithmic problem solving, machine learning pipelines, and production full-stack systems.

## Primary Technical Tracks & Domains

CodeLABS operates across three specialized technical domains:

1. **Artificial Intelligence & Machine Learning (AI/ML)**
   - Curriculum: Deep learning fundamentals, Computer Vision (YOLO, ViTs), Natural Language Processing (Transformers, LLM fine-tuning), PyTorch, TensorFlow, Edge AI, and autonomous agent systems.
   - Lead: Yash Mehla (Vice-President, Co-Founder & Head of Domain)

2. **Web & Fullstack Engineering**
   - Curriculum: Scalable web applications, modern React/Vite architectures, Node.js/Express and Spring Boot backend microservices, PostgreSQL/MongoDB, Redis caching, CI/CD pipelines, and cloud deployments.
   - Lead: Sourav Dhiman (President, Co-Founder & Head of Domain)

3. **Data Structures & Algorithms (DSA) & Competitive Programming**
   - Curriculum: Rigorous algorithmic problem solving, dynamic programming, graph theory, advanced data structures, competitive programming contests on Codeforces/LeetCode, and technical interview preparation.

# CodeLABS • Complete Knowledge Context

> Comprehensive guide to CodeLABS at Seth Jai Parkash Mukand Lal Institute of Engineering and Technology (JMIT), Radaur.

## 1. About CodeLABS

CodeLABS was established in August 2026 at JMIT Radaur with a mission to bridge the gap between academic computer science coursework and modern industry engineering standards. The club operates in cohort cycles with weekly code reviews, technical workshops, and internal hackathons.

## 2. Detailed Technical Curriculums

### 2.1 Artificial Intelligence & Machine Learning (Track 01)

- **Foundations**: Linear algebra, multivariate calculus, probability for ML, Python numpy/pandas vectorization.
- **Deep Learning**: PyTorch tensor operations, neural network architectures (MLP, CNN, RNN/LSTM), custom loss functions, backpropagation.
- **Computer Vision**: Object detection pipelines (YOLOv10, SSD), segmentation, Vision Transformers (ViTs), OpenCV edge deployment.
- **Natural Language Processing & Generative AI**: Tokenization, embedding spaces, Self-Attention mechanisms, Transformer architectures, Hugging Face ecosystem, parameter-efficient fine-tuning (LoRA), RAG (Retrieval-Augmented Generation) systems.
- **MLOps & Deployment**: Model export (ONNX, TensorRT), FastAPI inference endpoints, Docker containerization, cloud model hosting.

### 2.2 Full-Stack & Web Engineering (Track 02)

- **Frontend Architecture**: Modern React 18/19, TypeScript, state management (Zustand, Redux Toolkit), client-side routing, high-performance canvas/WebGL rendering, mobile responsiveness, accessible semantic HTML.
- **Backend Engineering**: RESTful APIs and GraphQL, Node.js/Express, Spring Boot microservices, middleware design, JWT and OAuth2 authentication, rate limiting.
- **Databases & Caching**: Schema design in PostgreSQL and MongoDB, indexing strategies, Redis caching layer, transaction management.
- **DevOps & Cloud**: Git workflows, GitHub Actions CI/CD pipelines, Docker, Linux server administration, Vercel/Cloudflare/AWS deployments.

### 2.3 Data Structures & Algorithms (Track 03)

- **Core Structures**: Arrays, linked lists, stacks, queues, hash maps, heaps, binary search trees, trie, segment trees, union-find (disjoint set).
- **Algorithmic Paradigms**: Two pointers, sliding window, binary search, divide and conquer, greedy algorithms, backtracking, dynamic programming (1D/2D/bitmask), graph traversals (BFS, DFS, Dijkstra, Floyd-Warshall, Kruskal, Prim).
- **Contest Practice**: Weekly virtual contests on LeetCode and Codeforces, editorial breakdowns, space/time complexity optimization.
